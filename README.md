# Dog-Treat-Dispenser
A device designed to dispense a dog treat and alert at a scheduled time for away-from-home medicine delivery.

## Requirments
* Arduino kit
  * Arduino board
  * breadboard
  *connection wires
  *servo
  *servo blade
  *buzzer
  *LED
  *button
*Arduino software
* cardboard or other construction material
* Hot glue
* box cutter or scissors
